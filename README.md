# Portfolio · Juan Segundo Sosa

Sitio estático: un solo `index.html` (estilos, marcado y animaciones) más las capturas en `img/`.
No tiene build ni dependencias.

## Ver en local

Abrí `index.html` en el navegador, o serví la carpeta:

```sh
npx serve .
```

## Deploy

Vercel publica la rama `main` tal cual (ver `vercel.json`: sin install ni build, sirve la raíz).
